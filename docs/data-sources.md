# Source ledger (checked 2026-09-27)

OpenCellID: daily export by 02:00 GMT, current export covers cells seen in prior 18 months; API has older records and 1,000 request credits/day; CSV includes estimates and observation counts but no usable signal strength (`averageSignal` is always zero). Dataset CC BY-SA 4.0. Country CSV download or daily changes require own key. https://docs.opencellid.org/docs/downloads/overview https://docs.opencellid.org/docs/downloads/daily-changes https://docs.opencellid.org/docs/getting-started/access-and-limits https://docs.opencellid.org/docs/downloads/database-format https://docs.opencellid.org/docs/attribution

Israel active antenna Govmap layer: last displayed update 2026-04-15; download API and reuse license not yet confirmed. DO NOT import by default. https://www.govmap.gov.il/?lay=233684

Ofcom UK road drive-test 4G/5G signal-strength releases, measured annually through 2025 (released 2026-03-06). This is genuine georeferenced signal, but only surveyed UK roads, not Israel or a live feed. Under open data policy; exact per-dataset license should be checked before redistributing. https://www.ofcom.org.uk/phones-and-broadband/coverage-and-speeds/mobile-signal-strength-measurement-data https://www.ofcom.org.uk/about-ofcom/our-research/opendata

Vienna 4G/5G measured scanner and UE drive-test dataset, CC BY 4.0, a research snapshot, not an updating feed. https://zenodo.org/records/18338399

Mozilla Location Service retired in 2024; not a viable input. https://github.com/mozilla/ichnaea/issues/2065

TU Dortmund DoNext: CC BY 4.0, georeferenced 4G/5G mobile measurements with latency and throughput, version 2 in 2026; research snapshot, not continuous feed. https://data.tu-dortmund.de/dataset.xhtml?persistentId=doi%3A10.17877%2FTUDODATA-2026-T6MYPO
