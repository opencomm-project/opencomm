SOURCE & LICENSE

DoNext H-Bahn

Schippers, H.; Geis, M.; Böcker, S.; Wietfeld, C. (2026), DoNext, TUDOdata V2. Related research article. The data is CC BY 4.0. opencomm selects and converts a sample; it does not change signal values.

METHOD

10,148 real rows

From the publicly available H-Bahn `cell_data.csv` (Dataverse file 81633), the exporter selects every 47th source row and retains rows with valid WGS84 coordinates and an observed RSRP within a plausible range. The sample is limited to the Dortmund area and retains row identifiers, source and license. Downloaded source MD5: 2319a9cefcd48839bf70a2198586fbb7. Read the exporter.

EVIDENCE GRADE

Measured RF

Each point is an observed reference-signal power (RSRP, dBm) at a place and recorded time. It is not a tower coordinate, estimated service area or promise of reception. The source calls operators only anonymized MNO codes A, B and C; it has MCC but no MNC, so these are not named carriers. Signal-type filters use observed NR SS-RSRP and LTE RSRP columns, not a claim that every record has an explicit 4G/5G network label. The separately retained source network label is present in only some rows and can indicate 5G NSA even where the point uses LTE RSRP.

EXPLORATORY MODEL

Predicted, not observed

A separate LightGBM model trains on coordinates from anonymized code C, NR SS-RSRP readings only. Five spatially blocked CV folds on the training set gave a weighted MAE of 6.50 dB (folds 2.17, 13.67, 8.70, 4.35, 3.61 dB); an additional untouched contiguous longitude segment (1,912 points) gave MAE 4.04 dB. These are along-route errors, not tests of adjacent ground. The published H3 resolution-10 hexes are within 150m of a source point. Fading opacity indicates a heuristic uncertainty from fold-model spread, CV error and distance to the route; it is not a calibrated probability or interval. A single narrow rail line cannot establish reliable RF coverage in nearby neighborhoods. Read model/export code and metrics JSON.

RECEPTION CENTERS

Grouped, not located towers

An exploratory third grade, estimated_reception_center, uses signal-strength-weighted receiver coordinates for groups with at least 20 sampled measurements sharing anonymized MNO code, cell_index, PCI and EARFCN. The source lacks MNC and full CGI; PCI can repeat. All samples run along one rail route, so the weighted center is pulled toward that route. These 24 markers are neither documented tower positions nor verified cell sites. No distance-error metric against tower ground truth exists yet. Read the exporter. A future sector-aware propagation layer requires valid tower/site anchors and independent spatial validation.

NOT YET HERE

No UK or Israel data

Ofcom publishes UK vehicle drive tests, but none are ingested. OpenCellID's Israel MCC 425 export requires a registered key and is not loaded. When licensed inventory arrives, it will be labeled `inferred_inventory`, not measured RF. The browser filters a static JSON extract and renders with MapLibre; there is no live server API on Pages.
